# Prius Parts — хэрэглэгчийн панел (демо)

**Toyota Prius-ийн сэлбэгийн онлайн дэлгүүр, хайбрид засварын цаг захиалгын системийн хэрэглэгчийн хэсэг.**

🔗 **Амьд демо:** https://kamui391.github.io/prius-parts-demo/

Туршилтын бүртгэл: `user@priusparts.test` / `User123!`

## Энэ демо юу вэ?

Дипломын ажлын бүрэн систем нь гурван хэсгээс бүрдэнэ: REST API сервер, хэрэглэгчийн панел, админ панел.
Энэ repo-д зөвхөн **хэрэглэгчийн панел** байна.

GitHub Pages сервер ажиллуулж чаддаггүй. Тиймээс демо горимд серверийн API-г хөтөч дотор дуурайдаг `src/demo/demoApi.js` ажиллана.
Каталог, үйлчилгээний өгөгдлийг жинхэнэ өгөгдлийн сангаас гаргасан агшин зургаас (`src/demo/data/snapshot.json`) уншина.
Таны хийсэн захиалга, цаг захиалга, гараж зэрэг нь зөвхөн таны хөтөчид (localStorage) хадгалагдана.
Дээд талын «Демог шинэчлэх» товч бүх өөрчлөлтийг арилгана.

## Боломжууд

- **Арлын дугаараар машин таних:** `ZVW30-1234567` → Prius 30, зөвхөн тохирох сэлбэгийг харуулна.
- **Каталог:** ангилал, Приусын үе, төлөв, үнэ, брэнд, үлдэгдлийн шүүлтүүр, ярианы нэрээр хайх («гупер» → бампер).
- **Үнийн харьцуулалт:** нэг сэлбэгийг олон нийлүүлэгч шинэ, хуучин, сэргээсэн төлөвөөр санал болгоно.
- **Сагс ба захиалга:** купон (`PRIUS10`, `WELCOME`, `HYBRID50`), хүргэлт, QPay QR төлбөр (sandbox), захиалгын явц.
- **Сэлбэг + суурилуулалт:** захиалга хийхдээ сервис дээр суурилуулах цагаа шууд сонгоно.
- **Засварын цаг захиалга:** сул цагийн хуанли, багтаамжийн хяналт.
- **Засвар үйлчилгээний зөвлөх:** Приусын үе, гүйлтийн км-ээр хийх ажлуудыг зөвлөнө.
- **Зардлын тооцоолуур, сэлбэг хүсэх, захиалга хянах, монгол/англи хэл, харанхуй горим.**

## Технологи

React 18 · Vite 5 · React Router 6 · lucide-react · өөрийн CSS дизайн систем.

## Локалаар ажиллуулах

```bash
npm install
npm run dev
```

`main` салбарт push хийхэд GitHub Actions сайтыг автоматаар build хийж GitHub Pages-д байршуулна.

> Нийлүүлэгч, үнэ, OEM дугаар зэрэг нь жишээ өгөгдөл.
